Scoring formula and limitations
SCORING & DATA LIMITS

Methodology

Static snapshot index ↗

The composite priority is a SubZer0 heuristic for triage—not an official CVSS, FIRST, CISA, or NVD score, and not proof of exploitation or safety. CVSS severity, EPSS probability, CISA KEV listing, and PoC references remain separately visible.

CVSS · 25%Numeric base score ÷ 10 × 100. Missing score is omitted.
EPSS · 25%FIRST probability × 100 only from a current, verified score set. Missing, stale, or unverified scores are omitted, never treated as zero.
CISA KEV · 25%100 when listed, 0 when not listed in this snapshot. Not listed does not mean never exploited.
PoC reference · 15%60 only when an NVD reference is explicitly tagged “Exploit”; that tag does not validate code. Missing tags are omitted. GitHub search counts are not scored.
Recency · 10%100 at observed activity time, declining linearly to 0 at 30 days, using the record’s sourced activity timestamp.

Available component weights are renormalized to 100. A score is shown only with at least 3 of 5 inputs; every value includes its input coverage. A missing component is uncertainty, not evidence of low risk. Source reference tags, product/version records, and CPEs are displayed only when supplied by the relevant source.

Freshness: NVD, GitHub advisories, and CISA do not currently publish per-source upstream update timestamps in this feed. The snapshot time is the collection run time, not source publication time; average source delay is therefore not calculated. FIRST EPSS freshness uses its actual score-set timestamp.

PoC: On-demand GitHub repository search shows the API’s matching repository count, not verified PoCs. Search absence is not proof no public PoC exists. No “confirmed” or “no public PoC” status is asserted without supporting evidence.

History: The rolling 30-day history compares complete snapshots. A material EPSS change means an absolute difference of at least 0.10, or a twofold change when both values are nonzero and the larger is at least 0.05; severity events require both snapshots to contain numeric CVSS, and KEV events compare IDs present in both snapshots. The static feed does not measure public attention, so no trending/hot ranking is claimed.

Automated alerts · NOT CONFIGURED: The static site has no secure server-side relay, Telegram bot/webhook credential, or authorized recipient/chat ID/webhook destination. No automated Telegram, Discord, or webhook delivery is active. “Share to Telegram” opens a user-triggered share link and sends no alert.
